# lost-found-practice

Производственная практика ПП.05.01, вариант 13: информационная система поиска потерянных вещей (веб-площадка объявлений о найденных и потерянных предметах).

Автор: Парамонов Михаил Михайлович, группа ВД-1-23.

## Структура репозитория

- `docs/week1` — неделя 1: анализ ресурсов (сравнение сайтов-аналогов, презентация № 1, скриншоты).
- `docs/week2` — неделя 2: презентация № 2, документ «Требования к дизайну», схема структуры и схема БД.
- `src` — основа сайта «НайдиВещь»: главная страница, лента, карточка, форма публикации, обращения; стили и скрипт.
- `database/schema.sql` — SQL-схема базы данных (users, categories, items, responses).

## Запуск

Откройте `src/index.html` в браузере. Сервер на этой стадии не нужен.
