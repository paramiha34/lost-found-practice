# Анализ сайтов-аналогов (неделя 1)

| Критерий | OLX («Бюро находок») | VRozyske.ru | «Потеряшки Сочи» |
|---|---|---|---|
| Публикация карточки | название, категория, до 8 фото, описание | пошаговая форма из шести блоков со шкалой заполнения | запись на стене сообщества: текст, фото, контакт автора |
| Поиск по признакам | поиск с регионом, категория, «только с фото», сортировка | базы розыска, поиск в шапке, выбор местоположения | по записям и хештегам |
| Обращение к автору | внутренний чат | форма или контакты | личное сообщение автору, комментарии по ходу решения |
| Закрытие объявления | снятие объявления, статуса возврата нет | есть статус закрытия | удаление записи или пометка «найдено» |

## Вывод

Ни один ресурс не закрывает все критерии. Для проекта нужны: различие «потеряно/найдено», карточка с категорией, местом и датой, поиск и фильтры, форма обращения к автору, закрытие со статусом возврата.
